Traveloop ✈️

Personalized Travel Planning Made Easy

Traveloop is a modern and intelligent travel planning platform designed to simplify multi-city trip management with a smooth and interactive user experience. The platform allows users to create personalized itineraries, manage expenses, discover destinations, organize activities, and track complete travel plans efficiently.

⚡ Workflow Overview

1. User Authentication

Users create accounts or log in securely through Supabase Authentication.

2. Trip Creation

Users can:

Create trips

Add destinations

Select travel dates

Add activities

Set budgets


3. Database Handling

Data is stored using relational database tables:

Users

Trips

Cities

Activities

Expenses

Packing Checklist


4. Real-Time Operations

CRUD Operations:

Create

Read

Update

Delete


All updates synchronize dynamically with the frontend.


---

🧠 Backend Architecture

The backend is powered by Supabase and relational database management using PostgreSQL.

Database Flow:

Authentication Request → User Validation

User Session → Secure Access

API Request → Database Processing

Database Response → Frontend Rendering


Security Features:

Row Level Security (RLS)

Protected APIs

User-Specific Data Access

Secure Authentication Tokens

🧪 Installation & Setup

Clone Repository

git clone https://github.com/your-username/traveloop.git

Navigate to Project

cd traveloop

Install Dependencies

npm install

Run Development Server

npm run dev


---

🔑 Environment Variables

Create a .env file and add:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
